# Current helpline results

This directory is for responsive helpline runs: working and missing-file task
variants with a reply, scoped repair and continued work. No reviewed model
recovery dataset is committed yet. Scripted tests are implementation evidence.

Keep manifests, native logs and exports together. Record model/provider errors,
no-contact, blocked, exhausted and failed episodes alongside successes. Results and this README are tracked in Git for publication alongside the code.
Keep credentials and private provider configuration out of run artifacts.
